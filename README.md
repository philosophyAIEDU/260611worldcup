# TACTIX 2026 ⚽

2026 FIFA 북중미 월드컵을 배경으로 한 브라우저 축구 경영 시뮬레이터.

48개 본선 진출국 중 한 팀을 선택해 조별리그부터 결승까지 대회 전체를 플레이합니다.
경기는 분 단위 텍스트 중계로 진행되며, 모든 데이터(48개국 × 26명 선수, 그룹 배정)는
코드에 내장되어 외부 API 없이 완전히 오프라인으로 동작합니다.

## 주요 기능

- **국가 선택** — 48개국의 FIFA 랭킹·전력 비교 후 팀 선택 (SVG 국기, 모든 OS에서 표시)
- **스쿼드 확인** — 팀당 26명(GK 3 / DF 8 / MF 8 / FW 7)의 실명 선수와 능력치
- **감독 모드** — 매 경기 전 당일 컨디션(70~100%)을 보고 선발 11명 직접 결정
- **전술 설정** — 포메이션 5종(4-3-3 / 4-4-2 / 4-2-3-1 / 3-5-2 / 5-3-2) + 성향(공격적/균형/수비적), 경기 결과에 실제 반영
- **경기 중 개입** — 작전 지시 패널에서 교체(최대 5명)와 성향 변경 가능
- **AI 수석코치** — Google Gemini(gemini-3.1-flash-lite)와 전술 상담. 본인 API 키 입력 필요(브라우저에만 저장), 키 없이도 게임은 완전히 동작
- **대회 진행** — 실제 2026 조추첨 기반 조별리그 3경기 → 32강 → 16강 → 8강 → 준결승 → 결승
- **라이브 중계** — 분 단위 이벤트 텍스트 (골 유형 9종, 핵심 선수 특별 중계)
- **업셋 시스템** — 랭킹 20위 이상 차이에서도 약팀 스타의 컨디션이 좋으면 이변 가능
- **승부차기** — 토너먼트 무승부 시 연장전 30분 후 능력치 기반 승부차기
- **자동 저장** — localStorage에 진행 상황 저장, 이어하기 지원

### AI 코치 사용법

1. 경기 준비 화면(또는 경기 중 작전 지시 패널)의 "AI 수석코치" 영역에 Gemini API 키 입력
2. 키 발급: [Google AI Studio](https://aistudio.google.com) → Get API key
3. 코치는 현재 매치업·선발 명단·컨디션·전술 규칙을 알고 있어 구체적인 상담 가능

## 로컬 실행

```bash
npm install
npm run dev
```

브라우저에서 표시된 주소(기본 http://localhost:5173)를 엽니다.

## 빌드 & Netlify 배포

```bash
npm run build
```

`dist/` 폴더가 생성됩니다. 배포 방법 두 가지:

1. **저장소 연결**: Netlify에서 이 저장소를 연결하면 `netlify.toml` 설정
   (`npm run build`, publish `dist`, SPA 리다이렉트)이 자동 적용됩니다.
2. **수동 업로드**: `npm run build` 후 `dist/` 폴더를 Netlify 대시보드에
   드래그&드롭하면 즉시 배포됩니다.

## 기술 스택

- React 18 + Vite 5
- 외부 API·서버 없음 (정적 배포)
- 저장: localStorage
