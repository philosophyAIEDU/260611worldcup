# TACTIX 2026 ⚽

2026 FIFA 북중미 월드컵을 배경으로 한 브라우저 축구 경영 시뮬레이터.

48개 본선 진출국 중 한 팀을 선택해 조별리그부터 결승까지 대회 전체를 플레이합니다.
경기는 분 단위 텍스트 중계로 진행되며, 모든 데이터(48개국 × 26명 선수, 그룹 배정)는
코드에 내장되어 외부 API 없이 완전히 오프라인으로 동작합니다.

## 주요 기능

- **언어 선택** — 첫 화면에서 한국어 / English 선택. English를 고르면 UI·중계·AI 코치까지 모두 영어로 표시되어 영어 학습 모드로 동작 (상단바에서 KO/EN 언제든 전환, 선택은 localStorage에 저장)
- **대회 선택** — 언어 선택 후 **FIFA 월드컵 2026**(48개국 국가대표) 또는 **UEFA 챔피언스리그**(유럽 32개 클럽) 선택. 두 대회 모두 동일한 감독 모드·AI 코치·영어 학습 기능을 한국어/영어로 즐길 수 있으며, 진행 상황은 대회별로 따로 저장됨 (홈에서 "다른 대회 선택"으로 전환)
  - **챔피언스리그** — 8개 조(조당 4클럽) 조별리그 → 16강 → 8강 → 준결승 → 결승. 클럽 스쿼드는 국가대표 데이터의 실제 선수를 소속 클럽별로 모아 구성하고 부족한 포지션은 보강해 채움
- **AI 영어 코치** — Google Gemini를 활용한 학습 기능. 축구 영어 단어·표현·중계 문장을 배우고, 단어 퀴즈를 풀고, 영어로 자유롭게 대화하면 문장을 친절하게 교정받음 (허브 화면에 상시 노출)
- **선수와 대화 (AI 페르소나)** — 선발·교체 화면에서 선수 옆 💬 버튼을 누르면 해당 선수가 1인칭으로 등장. 오늘 컨디션·각오·몸 상태를 직접 들을 수 있음 (Gemini)
- **AI 전술 코치 빠른 질문** — 상대 분석 리포트·스코어 예측·추천 전술을 버튼 하나로 요청
- **국가 선택** — 48개국의 FIFA 랭킹·전력 비교 후 팀 선택 (SVG 국기, 모든 OS에서 표시)
- **스쿼드 확인** — 팀당 26명(GK 3 / DF 8 / MF 8 / FW 7)의 실명 선수와 능력치
- **감독 역할 선택** — 팀 확정 후 5가지 역할(🎯 균형의 명장 / 🔥 동기부여가 / ⭐ 스타 조련사 / 🛡️ 철벽 수비 전문가 / ⚡ 공격 축구 전문가) 중 하나를 골라 대회 전체에 적용. 역할마다 매 경기 선수 컨디션을 소폭(+2~4%) 보정 (허브 상단에 현재 역할 표시)
- **팀 토크 (경기 전 동기부여)** — 킥오프 전 감독의 한마디(🔥 열정적 격려 / 🧊 침착하게 / 😤 강하게 질책 / 🎯 전술 집중 / 🤐 생략)를 선택해 선발진의 분위기를 끌어올림. 선택 즉시 선발 명단의 컨디션(%)에 반영되어 효과를 눈으로 확인 (보정폭은 +1~3%로 현실적인 수준, 동기부여가 역할은 팀 토크 효과 강화)
- **주장 선택** — 선발 11명 중 주장을 지정. 주장 본인 컨디션 +2%, 팀 전체 리더십 +1% 보너스
- **감독 모드** — 매 경기 전 당일 컨디션(70~100%)을 보고 선발 11명 직접 결정
- **전술 설정** — 포메이션 5종(4-3-3 / 4-4-2 / 4-2-3-1 / 3-5-2 / 5-3-2) + 성향(공격적/균형/수비적), 경기 결과에 실제 반영
- **경기 중 개입** — 작전 지시 패널에서 교체(최대 5명)·성향 변경·**포메이션 변경**까지 가능
- **게임 속도 조절** — 경기 화면에서 4단계 속도(🐢 느리게 / ▶ 보통 / ⏩ 빠르게 / ⚡ 매우 빠르게) 직접 선택, 설정은 저장되어 다음 경기에도 적용
- **쿼터 휴식 설정** — 매 쿼터 종료 시 자동으로 쉬며 작전을 가다듬을지(기본), 쉬지 않고 바로 다음 쿼터로 넘어갈지 선택 가능. 쿼터 브레이크 중 "이후 휴식 없이 진행"으로 즉시 끌 수도 있음 (설정 저장)
- **AI 수석코치** — Google Gemini(gemini-3.1-flash-lite)와 전술 상담. 본인 API 키 입력 필요(브라우저에만 저장), 키 없이도 게임은 완전히 동작
- **대회 진행** — 실제 2026 조추첨 기반 조별리그 3경기 → 32강 → 16강 → 8강 → 준결승 → 결승
- **4쿼터 경기** — 전후반이 아닌 4쿼터(Q1~Q4) 구성으로 진행, 분 단위 라이브 중계
- **업셋 시스템** — 랭킹 20위 이상 차이에서도 약팀 스타의 컨디션이 좋으면 이변 가능
- **승부차기** — 토너먼트 무승부 시 연장전 30분 후 능력치 기반 승부차기
- **자동 저장** — localStorage에 진행 상황 저장, 이어하기 지원

### AI 코치 사용법 (전술 + 영어 학습)

1. 경기 준비 화면(또는 경기 중 작전 지시 패널)의 "AI 수석코치", 혹은 허브 화면의 "AI 영어 코치" 영역에 Gemini API 키 입력 (두 코치가 같은 키를 공유)
2. 키 발급: [Google AI Studio](https://aistudio.google.com) → Get API key
3. **전술 코치**는 현재 매치업·선발 명단·컨디션·전술 규칙을 알고 구체적으로 상담하며, 선택한 언어로 답함
4. **영어 코치**는 축구 영어를 가르치는 튜터로, 버튼 한 번으로 단어 학습·5문항 퀴즈·오프사이드 설명·중계 표현을 요청할 수 있고, 영어로 입력하면 문장을 교정해 줌

## 로컬 실행

```bash
npm install
npm run dev
```

브라우저에서 표시된 주소(기본 http://localhost:5173)를 엽니다.

## 빌드 & Netlify 배포

```bash
npm run build
```

`dist/` 폴더가 생성됩니다. 배포 방법 두 가지:

1. **저장소 연결**: Netlify에서 이 저장소를 연결하면 `netlify.toml` 설정
   (`npm run build`, publish `dist`, SPA 리다이렉트)이 자동 적용됩니다.
2. **수동 업로드**: `npm run build` 후 `dist/` 폴더를 Netlify 대시보드에
   드래그&드롭하면 즉시 배포됩니다.

## 기술 스택

- React 18 + Vite 5
- 외부 API·서버 없음 (정적 배포)
- 저장: localStorage

## 프로젝트 구조

```
src/
├── main.jsx / App.jsx     앱 진입점과 화면 상태 머신
├── data/
│   ├── playerFactory.js   선수/팀 데이터 팩토리
│   ├── competitions.js    대회 정의 (월드컵 / 챔피언스리그 포맷·그룹)
│   ├── groups.js          2026 월드컵 그룹 배정 (실제 조추첨 기반)
│   ├── clubs/             챔피언스리그 32개 클럽 스쿼드 구성·조 배정
│   └── teams/             48개국 × 26명 선수 데이터 (대륙별 분할)
├── engine/
│   ├── matchEngine.js     경기 시뮬레이션 (컨디션·업셋·승부차기)
│   ├── commentary.js      한국어 중계 텍스트 생성
│   ├── tournament.js      조별리그 순위·진출팀 선별·토너먼트 대진 (두 포맷 공용)
│   └── storage.js         localStorage 저장/불러오기 (대회별 분리)
└── components/            UI 컴포넌트
```
